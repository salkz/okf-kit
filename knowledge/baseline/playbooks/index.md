# Playbooks

* [Make a change](make-a-change.md) - The loop for any change: branch, change with a test, run the checks, update the knowledge, commit atomically, open a pull request.
* [Update the knowledge](update-knowledge.md) - How to keep the bundle true: what to edit, when, how trust is recorded, and where local concepts go.
* [Review the knowledge](review-knowledge.md) - How a person checks the concepts agents wrote, verifies them or asks for changes.
* [Process change requests](process-change-requests.md) - How an agent answers the change requests a reviewer left in the review tool.
* [Write the first local knowledge](bootstrap-knowledge.md) - How an agent fills an empty local bundle in a repository that already has code.
* [Update the baseline](update-baseline.md) - How to move a repository to a newer version of the kit and its baseline.
